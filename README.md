# kuka 🎵

Application de musique gratuite (avec pubs) inspirée de Spotify. Le mode Premium arrive bientôt.

## Fonctionnalités
- 8 titres synthétisés dans le navigateur (aucun fichier audio requis)
- Lecteur complet : lecture/pause, suivant/précédent, aléatoire, répétition, progression, volume
- Recherche, favoris et playlists
- Réglages : thème, lecture automatique, profil par pseudo
- Publicités (toutes les 3 pistes) et page Premium à venir (variable PREMIUM dans index.html)
- Import de tes propres fichiers audio et de pochettes (durée de la session)

## Utilisation
Ouvre `index.html` dans un navigateur, ou publie le dépôt avec GitHub Pages.

## Publier avec GitHub Pages
1. Settings → Pages
2. Source : Deploy from a branch → `main` → `/ (root)` → Save
3. Ton app sera en ligne sur `https://TON-PSEUDO.github.io/kuka/`
